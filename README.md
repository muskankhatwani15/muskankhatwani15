# Muskan Khatwani Portfolio

A modern static portfolio website for Muskan Khatwani, highlighting her experience as a Software Engineer with a strong focus on C++, AB Suite, debugging, production troubleshooting, and open-source C++ contribution.

## Overview

This project is a single-page personal website built with plain HTML, CSS, and JavaScript. It presents:

- professional summary
- key technical skills
- work experience
- projects and contributions
- open-source work
- education and achievements

## Project Files

- `index.html` — the complete portfolio page
- `README.md` — project overview and usage instructions

## Features

- animated intro hero section
- fixed navigation and responsive mobile menu
- skills and technology sections
- experience timeline with professional highlights
- open-source contribution section for `fmtlib/fmt`
- project cards and media-style visual blocks
- polished light theme design

## Run Locally

### Option 1: Open directly
Open `index.html` directly in a browser.

### Option 2: Local server
From the project folder, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- The design uses Google Fonts, so internet access is recommended for the best appearance.
- No framework or dependency installation is required.
- The site is static and works as a lightweight portfolio or personal landing page.

## Purpose

This portfolio is designed to present Muskan's software engineering profile to recruiters, hiring teams, and collaborators in a polished, professional format.
